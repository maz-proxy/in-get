# Arunika

Prototype dashboard keuangan dan akuntansi bisnis berbahasa Indonesia. Identitas visual dan komponen dibuat khusus, sebagai fondasi aplikasi pembukuan yang lebih lengkap.

## Menjalankan aplikasi

Pastikan Node.js dan npm tersedia, lalu jalankan `npm install` untuk memasang dependensi dan `npm run dev` untuk membuka server pengembangan. Untuk memeriksa hasil produksi, jalankan `npm run build`.

## Cakupan saat ini

- Ringkasan saldo kas dan bank, pemasukan, pengeluaran, dan piutang.
- Grafik arus kas enam bulan serta transaksi terbaru dengan data contoh.
- Pintasan pembuatan transaksi, tagihan, dan pencatatan pengeluaran.
- Navigasi dashboard, transaksi, penjualan, pembelian, persediaan, laporan, dan pengaturan.

Data pada prototipe ini bersifat statis dan belum tersambung ke basis data atau layanan akuntansi.
